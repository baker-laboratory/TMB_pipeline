# Changelog of v1.x


## v1.1.0 (04/29/2025)

This is the start of changelog, many features are added in this version but not well documented. Please feel free to add missing features and bug fixes.

- Fix the PDB loading bug. by Joe Min in https://git.ipd.uw.edu/justas/fused_mpnn/-/merge_requests/29
- Support load motif information from CIF files. by Rafi in https://git.ipd.uw.edu/justas/fused_mpnn/-/merge_requests/25
- Replace `prody` with `biotite` to write PDB/CIF files. by Rafi, Joe Min, and Raktim in https://git.ipd.uw.edu/justas/fused_mpnn/-/merge_requests/26
- Add training scripts. by Zhichun.
- Add unit tests for the new dataloader. by Andrew K, Joe Min, Carlo, and Zhichun.
